# ApexPlanet Internship — Task 3: Code & Chill

Built with HTML, CSS, and vanilla JavaScript.

## Requirements covered
1. Responsive design using CSS media queries, including a mobile navigation menu.
2. Interactive five-question quiz with correct/incorrect feedback, progress, score, and restart.
3. Fetches a programming joke from the public JokeAPI endpoint and displays it dynamically.

## Run
Open this folder in VS Code and run `index.html` using Live Server, or open it in a browser. Internet access is required for the API feature; the quiz works offline.

## Test before submission
- Select correct and incorrect quiz answers; finish the quiz and use Try again.
- Click Get a programming joke.
- Resize the browser to mobile and desktop widths; test the Menu button.
- Check the browser console for errors.
