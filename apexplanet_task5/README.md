# ApexPlanet Internship — Task 5: StudyFlow

A responsive student productivity dashboard built with HTML, CSS and JavaScript.

## Features
- Dashboard task statistics and completion progress.
- Add, complete, remove, filter and search tasks.
- Local Storage persistence for tasks and appearance preference.
- 25-minute Pomodoro focus timer with pause/resume/reset.
- Light/dark mode and responsive mobile navigation.
- Accessible labels, status messages and reduced-motion support.

## Run
Extract the ZIP, open this folder in VS Code and run `index.html` with Live Server, or open it directly in a modern browser. No dependencies, external fonts, images, API keys or build steps are required.

## Test before submission
1. Add a task and refresh; verify it remains saved.
2. Complete a task and check the statistics.
3. Test All, Pending and Completed filters and search.
4. Start, pause, resume and reset the timer.
5. Toggle dark mode and refresh.
6. Test mobile navigation and resize to different widths.
7. Test in Chrome and another available browser.

This is a front-end demo without a backend or cloud sync. Clearing browser site data removes locally saved tasks.
