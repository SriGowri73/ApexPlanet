# ApexPlanet Internship — Tasks 1 & 2

## Included
- `task1/`: Basic webpage with headings, paragraphs, image, links, CSS styling, responsive layout, and JavaScript alert.
- `task2/`: Contact form with JavaScript validation, responsive Flexbox/Grid layout, and dynamic to-do list with add/complete/remove.

## Run locally
1. Extract the ZIP.
2. Open the `task1` folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).
4. Repeat for the `task2` folder.

No build tools or packages are required. The Task 1 photo is loaded from Unsplash, so it needs an internet connection. Task 2 form validation is a demo and does not send messages to a server.

Before submitting, personalize the text and test the pages on desktop and mobile widths. Record a screen demo, upload the video to LinkedIn Featured, push each task folder (or both folders) to a public GitHub repository, and submit both links through the internship portal as described in your PDF.
