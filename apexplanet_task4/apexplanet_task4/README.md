# ApexPlanet Internship — Task 4

## Features
- Responsive personal portfolio with About, Projects, and Contact sections.
- Mobile navigation menu using JavaScript and CSS media queries.
- To-Do List saved in browser Local Storage (tasks remain after refresh).
- Product listing with category filtering and sorting by price or rating.
- Contact form client-side validation.

## Run locally
Open `index.html` in your browser, or open this folder in VS Code and use Live Server. No dependencies or build step are needed.

## Customize before submitting
- Replace `Your Name` and `YN` with your own name/initials.
- Edit the About, skills and project descriptions so they truthfully reflect your experience.
- Test Local Storage by adding a task and refreshing.
- Test each category and sorting option, then test the layout on a narrow/mobile viewport.

The contact form is a frontend demo only; it does not send email or store messages on a server.
